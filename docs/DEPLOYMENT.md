# Deploying the dashboard and API

## Run the dashboard locally

```bash
pip install -r app/requirements.txt
streamlit run app/streamlit_app.py
```

With no `DATABASE_URL`, the app starts in **demo mode**. It reads the bundled synthetic sample in `app/sample_data/`
(25 tickers, 3 years, generated by `scripts/load_sample_data.py`, not real prices), and a yellow **DEMO MODE** badge
shows on every page. Set `DATABASE_URL` and it reads the live database instead, and the badge turns green.

The app only runs `SELECT` statements on the reporting views, inside `SET TRANSACTION READ ONLY` transactions
(`marketintel/datasource.py`). Even so, give it the **read-only login**, never the owner connection string:

```sql
CREATE ROLE dashboard_reader WITH LOGIN PASSWORD 'a-long-random-password';
GRANT readonly_access TO dashboard_reader;
```

Query results are cached for 10 minutes (`st.cache_data(ttl=600)`), so a public dashboard sends Neon at most a few queries
per page every 10 minutes.

## Streamlit Community Cloud

1. Sign in at **https://share.streamlit.io** with the GitHub account that owns the repository.
2. Click **Create app → Deploy a public app from GitHub** and fill in:
   - **Repository:** `Bhavex/market-intelligence-pg`
   - **Branch:** `main`
   - **Main file path:** `app/streamlit_app.py`
   - **App URL:** choose a subdomain, e.g. `nse-sector-intelligence`
3. Open **Advanced settings** and choose **Python 3.12**. Streamlit Cloud installs `app/requirements.txt`, which is
   next to the entrypoint and takes precedence over the root `requirements.txt`.
4. **For demo mode, stop here and click Deploy.** No secrets are needed.
5. **For live data**, paste this into **Advanced settings → Secrets** (TOML), using the read-only login:
   ```toml
   DATABASE_URL = "postgresql://dashboard_reader:PASSWORD@HOST/neondb?sslmode=require"
   ```
   The app reads `DATABASE_URL` from the environment first, then from `st.secrets`. Secrets entered here are stored by
   Streamlit, never in the repository.
6. Deploy. Later pushes to `main` redeploy automatically. If you change secrets, use **⋮ → Reboot app**.

The theme comes from `.streamlit/config.toml` at the repository root, which Streamlit Cloud picks up automatically.

**Troubleshooting**
- *"Data is not available right now"*: the database refused or timed out. Neon's free tier suspends idle compute,
  so the first query after a pause can take a few seconds. Reload the page.
- *Permission denied for relation …*: the role is missing `readonly_access`; run the `GRANT` above.

## REST API

```bash
pip install -r api/requirements.txt
uvicorn api.main:app --reload
```

Interactive docs are at `http://localhost:8000/docs`. The API uses the same data source as the dashboard: demo data
without `DATABASE_URL`, read-only views with it.

It can run on any host that runs a Python web process (Render, Railway, Fly.io, a VM):
- **start command:** `uvicorn api.main:app --host 0.0.0.0 --port $PORT`
- **environment variable:** `DATABASE_URL` set to the read-only login above

## Everything at once with Docker

See **Run it with Docker** in the README. `docker compose up --build` starts PostgreSQL, applies the schema, loads
10 years of synthetic data, and serves the dashboard on port 8501 and the API on port 8000.
